# Gauges

Progress indicators, stacked gauges, and LCD digit displays.

| Example | Description |
|---------|-------------|
| `gauge.js` | Single gauge with fractional fill |
| `gauge-list.js` | Multiple gauges in a vertical list |
| `gauge-stack.js` | Gauge with stacked percentage segments |
| `lcd.js` | LCD digit display with real-time segment tuning |

## Quick start

```bash
node ./examples/gauges/gauge.js
```
