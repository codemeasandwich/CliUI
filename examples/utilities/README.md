# Utilities

Server rendering, widget introspection, and drag-handling test helpers.

| Example | Description |
|---------|-------------|
| `prototypes.js` | Widget introspection via `getOptionsPrototype` |
| `server-render.js` | Server-side rendering utilities for HTTP responses |
| `blessed-drag-test.js` | Native blessed drag functionality test |

## Quick start

```bash
node ./examples/utilities/prototypes.js
```
