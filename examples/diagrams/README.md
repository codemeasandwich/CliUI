# Diagrams

Diegetic ASCII diagram editor with programmatic model building, drag routing, and workflow visualisation.

| Example | Description |
|---------|-------------|
| `diagram.js` | Interactive diagram editor with keyboard navigation |
| `diagram-pipeline.js` | CI/CD pipeline built programmatically |
| `diagram-checklist.js` | Sprint board with checked-state workflow |
| `diagram-topology.js` | Infrastructure topology with headless parse/render |
| `diagram-drag.js` | Click-and-drag with A* routing and debug overlays |
| `diagram-drag-debug.js` | Debug infrastructure helper (not standalone) |
| `diagram-workflow.js` | Workflow planner with animated state transitions |

## Quick start

```bash
node ./examples/diagrams/diagram.js
```
