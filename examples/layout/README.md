# Layout

Grid systems, carousels, and cutout border effects.

| Example | Description |
|---------|-------------|
| `grid.js` | Grid-based layout engine with borders |
| `grid-no-border.js` | Grid layout without visible borders |
| `carousel.js` | Multi-page carousel with rotation |
| `carousel-no-rotate.js` | Carousel that stops at boundaries |
| `cutout-demo.js` | Visual cutout/border effect demo |
| `cutout-quick.js` | Minimal cutout feature demo |
| `cutout-tabbar.js` | Cutout combined with a tab bar |

## Quick start

```bash
node ./examples/layout/grid.js
```
