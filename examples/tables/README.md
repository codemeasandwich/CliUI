# Tables

Data tables, tree views, and interactive file explorer.

| Example | Description |
|---------|-------------|
| `table.js` | Interactive table with VI keybindings |
| `table-auto-width.js` | Table with auto-calculated column widths |
| `table-color.js` | Table with custom foreground colours |
| `table-percentage-width.js` | Table with percentage-based column widths |
| `tree-extended.js` | Tree widget with extended nodes and tree lines |
| `explorer.js` | Tree + table split-view filesystem explorer |

## Quick start

```bash
node ./examples/tables/table.js
```
