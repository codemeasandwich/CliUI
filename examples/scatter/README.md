# Scatter Plots

Coordinate-based point plot visualisations.

| Example | Description |
|---------|-------------|
| `scatter.js` | Basic scatter plot with marker styles |
| `scatter-multi.js` | Multi-series scatter plot with legend |
| `scatter-markers.js` | Demonstrates all marker types (o, +, x, *, .) |
| `scatter-bounds.js` | Scatter plot with explicit axis bounds |

## Quick start

```bash
node ./examples/scatter/scatter.js
```
