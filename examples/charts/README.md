# Charts

Line charts, bar charts, donut/pie charts, and sparkline widgets.

| Example | Description |
|---------|-------------|
| `bar.js` | Bar chart with configurable bar width and spacing |
| `stacked-bar.js` | Stacked bar chart with category segments |
| `donut.js` | Donut/pie chart with multiple arcs |
| `line-fraction.js` | Simple line chart with fraction-based Y labels |
| `line-abbreviate.js` | Line chart with abbreviated axis labels |
| `line-random-colors.js` | Line chart using 256-colour palette |
| `line-start-above-zero.js` | Line chart with a custom minY baseline |
| `line-ypadding.js` | Line chart with vertical padding control |
| `line-zoomed-in.js` | Line chart with tight Y-axis zoom |
| `multi-line-chart.js` | Multi-series line chart with legend |
| `sparkline.js` | Compact single-row sparkline |
| `sparkline-simple.js` | Sparkline with tags disabled |

## Quick start

```bash
node ./examples/charts/bar.js
```
