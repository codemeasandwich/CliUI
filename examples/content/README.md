# Content

Markdown rendering, scrollable logs, world map, and image display widgets.

| Example | Description |
|---------|-------------|
| `markdown.js` | Markdown rendering with colour styling |
| `markdown-styled.js` | Markdown with custom chalk colour styles |
| `marked-terminal.js` | Markdown-to-terminal with checkbox support |
| `log.js` | Scrollable logging widget |
| `log-scroll.js` | Log widget with manual scroll control |
| `map.js` | World map with marker placement |
| `picture.js` | Image rendering from PNG |

## Quick start

```bash
node ./examples/content/markdown.js
```
