# Galactica Examples

Interactive examples demonstrating the full range of Galactica terminal UI widgets.

## Running an Example

```bash
node ./examples/dashboards/dashboard.js
```

## Categories

| Folder | Description |
|--------|-------------|
| [charts/](./charts/) | Line charts, bar charts, donut charts, and sparklines |
| [scatter/](./scatter/) | Scatter and point plot visualisations |
| [gauges/](./gauges/) | Gauge widgets, stacked gauges, and LCD displays |
| [tables/](./tables/) | Data tables, tree views, and file explorer |
| [layout/](./layout/) | Grid layouts, carousels, and cutout borders |
| [diagrams/](./diagrams/) | ASCII diagram editor, pipelines, and workflow visualisation |
| [content/](./content/) | Markdown, logs, maps, and image rendering |
| [dashboards/](./dashboards/) | Multi-widget dashboard compositions |
| [utilities/](./utilities/) | Server rendering, widget introspection, and drag testing |
| [inline-data/](./inline-data/) | Self-contained variants with hardcoded data (useful for CI) |
